# Moron Guard asset

`moron-guard.png` is the project mascot and package-gallery image. ChatGPT generated the original image on 2026-08-12. The prompt followed the monochrome mascot style from the existing whiskd, gang, and da bridge design conversation.

The final prompt asked for:

- an original, unimpressed command-line sentry that blocks destructive shell commands;
- a stop gesture, terminal prompt, and terminal shield;
- a stark black-and-white, hand-inked, screen-printed style;
- a centered square mark that remains clear at small sizes;
- no color, gradients, thin lines, realistic rendering, robot face, padlock, weapon, police badge, or copied mascot;
- no text unless a small secondary `MORON GUARD` mark remained clear.

The downloaded image was resized to 1024 by 1024 pixels and optimized as a 32-level grayscale PNG. The visual content did not contain color or transparency before this conversion.
